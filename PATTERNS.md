## How to use

1. Solve a problem and identify its underlying technique.
2. Copy `templates/pattern-template.md` into `patterns/<pattern-name>.md` when learning a new pattern.
3. Record recognition clues, invariants, complexity, mistakes and related problems.
4. Add a link to the pattern note in this index.
5. Revisit the pattern using an unfamiliar problem.

## Confidence scale

- 1: Cannot recognize or explain the technique.
- 2: Recognize it with hints.
- 3: Understand it but need implementation help.
- 4: Implement independently and justify correctness.
- 5: Apply it independently to unfamiliar variations.

Pattern classifications for the initial problems are suggested; update them to match the approaches actually used.
