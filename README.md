# CSES Problem Solving

A personal journey to strengthen my problem-solving skills, algorithmic thinking, and understanding of data structures and algorithms through the [CSES Problem Set](https://cses.fi/problemset/).

The goal is simple: **solve problems consistently, understand the logic behind each solution, and improve one day at a time.**

## Goals

- Solve 2 problems daily.
- Strengthen Python and C++ programming skills.
- Improve logical thinking and algorithm design.
- Understand time and space complexity.
- Document approaches, mistakes, and key learnings.
- Build consistency through daily practice.

## My Approach

For each problem:

1. Understand the problem and constraints.
2. Work through sample inputs manually.
3. Develop an approach before coding.
4. Implement and test the solution.
5. Analyze time and space complexity.
6. Document what I learned.

I prioritize understanding over memorizing solutions.

## Daily Challenge

**Target:** 2 problems per day

**Languages:** Python and C++

**Platform:** [CSES Problem Set](https://cses.fi/problemset/)

Some problems may take longer than others. The focus is on consistent improvement rather than rushing through the problem set.
